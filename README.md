# Análisis de Datos con Python

Repositorio creado para almacenar las actividades desarrolladas durante el curso de Análisis de Datos con Python.

## Estructura

- `notebooks/`: notebooks desarrollados durante el curso.
- `data/raw/`: datos originales.
- `data/processed/`: datos procesados.
- `src/`: funciones de Python.
- `reports/figuras/`: figuras y resultados gráficos.

## Contenido

- Semana 02: Introducción.
- Semana 03: Fundamentos de Python.
- Semana 04: Funciones y modularización.

## Herramientas

- Python
- Pandas
- Google Colab / Jupyter Notebook
- Git
